# На объекте — Инструкция для бригад ГСС

Этот раздел для специалистов, выезжающих на объекты. Здесь — пошаговые действия при типовых ситуациях.

## Общий принцип

Перед обращением к специалистам Монитрона выполнить полный цикл первичной диагностики.

Любое предположение о программной неисправности допускается **только после исключения физических причин**.

## Что взять с собой на объект

- Мультиметр
- Монитор-тестер + переходник
- ЗИП — запасные головки датчиков
- Ультрафиолетовый фонарь (для поиска протечек)
- Терминальный резистор
