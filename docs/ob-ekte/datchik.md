# Датчик не определяется

## Обязательные проверки по порядку

1. Проверить питание
2. Проверить полярность подключения
3. Проверить целостность линии
4. Проверить сопротивление мультиметром
5. Проверить отсутствие короткого замыкания
6. Проверить разъёмы
7. Перезапустить питание датчика
8. Подключить монитор-тестер
9. При наличии ЗИП — заменить головку на заведомо исправную

Только после выполнения всех пунктов допускается обращение в Монитрон.

## Работа с монитором-тестером

Монитор-тестер показывает картинку, которую видит процессор датчика.

**Нормальное изображение:**

- Кружок чёткий, по центру
- Без ореолов и шумов вокруг
- Без смещения

Если изображение кривое — датчик требует юстировки. Скорректировать положение оптики вручную до получения нормальной картинки.

!!! tip
    Без данных монитора-тестера диагностика считается неполной.

## Если датчик не запускается при монтаже

Не пытаться запустить повторно долго. Сразу заменить на другую голову из ЗИП.

Зафиксировать номер снятого датчика и передать в Монитрон с карточкой неисправности.
