# Финальный контроль после любых работ

Перед уходом с объекта — обязательный обход.

## Чек-лист

- [ ] Закрыты крышки всех датчиков
- [ ] Герметичность соединений проверена
- [ ] Кабели закреплены
- [ ] Гофра закреплена
- [ ] Питание есть
- [ ] Данные появились на сервере
- [ ] Аварий нет
- [ ] Фото результата сделано и отправлено в чат

Объект считается сданным только после выполнения полного чек-листа.

!!! tip "Правило финального обхода"
    Как при замене колёс: после всего — ещё раз руками протягивают каждый болт. Здесь то же самое — финальный обход обязателен, даже если всё выглядит нормально.
