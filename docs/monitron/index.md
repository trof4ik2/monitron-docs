# Монитрон — Работа операторов

Этот раздел для операторов мониторинга. Здесь описаны все задачи, которые выполняются удалённо: работа с системой Монитрон, удалённые ПК, ошибки и их решение.

## Основные задачи оператора

- Закрытие скачков данных длительностью от 30 минут
- Сбор информации по проблемным датчикам, отслеживание динамики
- Скрытие проблемных датчиков с графика и плана
- Контроль состояния удалённых ПК и скриптов
- Корректировки и сглаживания на общих графиках
- Помощь бригадам ГСС и Монитрон при выездах
- Постановка и снятие объектов с ТО
- Замена голов датчиков в системе

## С чего начать смену

1. Открыть главную страницу Монитрона
2. Проверить индикацию объектов — нет ли красных или оранжевых
3. Проверить окно «Датчики без показаний» — нет ли новых
4. Проверить окно «Скачки для ручного решения от получаса»
5. Пройтись по таблице проблемных датчиков — обновить статусы
